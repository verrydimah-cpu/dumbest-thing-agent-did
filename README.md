One line, at most 200 characters, on the dumbest thing my agent did today. The program writes that single line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, or `/output`): an agent that spent two hours building a licensed GitHub repo and a test harness just to print one line calling itself dumb — then ran it twice to check the line hadn't changed.

## Run it

```sh
node main.ts
```
